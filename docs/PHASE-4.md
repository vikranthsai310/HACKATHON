## 🔧 Component Guide

### ChatBot.jsx
Main container managing conversation state and API calls.

### Message.jsx
Individual message bubble for user/system messages.

### DecisionCard.jsx
Displays HRM decision results with explanation.

### InputBar.jsx
Text input with send button.
